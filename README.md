# Marie

A cross-platform warframe companion overlay.

> [!CAUTION]
> Use at your own risk. this is a personal project and not an official tool. 
> It is heavily AI assisted as of right now, since i just wanted to get something working quick before making it better.

## Why make this when aleca frame exists?

Aleca Frame is pretty good, but it requiring overwolf and it reading memory made me uncomfortable. 
I wanted to make something that is purely log parsing and screen capture based.
I also dislike having overwolf running in the background and the fact that aleca frame is windows only. (i am on linux)

It should be safe because it does not mess with the game's memory at all, instead just relies on the logs the game saves 
and screen captures, but as with everything, use at your own risk

## Features

- [x] Relic drop prices in platinum and ducats 
- [ ] Riven mod roll calculator
- [ ] Mastery rank calculator

## Supported platforms
- Windows 10/11 (not tested but should work?)
- Linux (Wayland only, tested on Hyprland)
